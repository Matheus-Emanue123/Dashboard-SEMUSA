# SEMUSA

## Estrutura do repositório

Este repositório contém os seguintes arquivos de configuração e documentação:

### [`LICENSE`](./LICENSE)
Define os termos legais sob os quais o código deste projeto pode ser usado, copiado, modificado e distribuído por terceiros. Deve conter o texto de uma licença de código aberto (ex: MIT, Apache 2.0, GPL) já preenchido com o nome do titular dos direitos e o ano. Sem esse arquivo, o código é considerado "todos os direitos reservados" por padrão.

### [`CODEOWNERS`](./CODEOWNERS)
Define quem são os responsáveis (donos) por partes específicas do código. Deve conter uma lista de caminhos de arquivos/pastas associados a usuários ou times do GitHub (ex: `*.js @usuario`), usada para solicitar revisão automática em Pull Requests que alterem esses caminhos.

### [`Contributing.md`](./Contributing.md)
Guia para quem deseja contribuir com o projeto. Deve conter instruções como: como configurar o ambiente de desenvolvimento, padrão de commits, como abrir Pull Requests, regras de estilo de código e processo de revisão.

### [`.gitignore`](./.gitignore)
Lista os arquivos e pastas que o Git deve ignorar (não versionar). Deve conter padrões como dependências (`node_modules/`), arquivos de build, variáveis de ambiente (`.env`) e arquivos temporários/de IDE.

### `README.MD`
Este arquivo. Serve como porta de entrada do repositório, explicando o que é o projeto e como o repositório está organizado.
